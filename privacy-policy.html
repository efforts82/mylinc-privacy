마이린 개인정보처리방침

시행일 · 2026년 10월 9일

마이린(mylinc)은 리니지 클래식의 캐릭터 정보 확인, 성장·아이템·사냥 기록 및 알림을 제공하는 브라우저 확장프로그램입니다. 운영자는 아래와 같이 정보를 처리합니다.

1. 처리하는 정보와 목적

  • 공식 홈페이지 정보: 로그인 상태, 캐릭터 목록·식별정보(이름·서버 등), 레벨·경험치·스탯·혈맹·캐릭터 관련 날짜, 착용장비, 인벤토리·창고의 아이템·수량·아데나 및 이미지 등 홈페이지에서 제공되는 정보를 연결 확인과 화면 표시, 변화 기록에 사용합니다.
  • 계산·저장되는 기록: 경험치와 레벨업 이력, 아이템 증감, 사냥 시작·종료·사냥터·성과 등을 기록 조회와 분석에 사용합니다.
  • 직접 입력한 정보: 메모, 가계부의 구매·판매 일시·아이템·수량·가격·메모, 퀘스트와 완료 기록, 알림 이름·시각·반복·음량, 직접 만든 버프, 아이템 가격·기간, 목표 레벨, 즐겨찾기, 장비 지정 및 화면 설정을 해당 기능 제공에 사용합니다.
  • 진단 정보: 수집 시각·단계·성공/실패·응답 상태와 아이템 응답·변동 비교에 필요한 진단 정보를 오류 확인을 위해 브라우저에 제한된 크기로 보관할 수 있습니다.

공식 홈페이지의 로그인 화면에서 인증하며, 마이린은 로그인 아이디·비밀번호를 입력받거나 별도로 저장하지 않습니다. 홈페이지 조회에는 브라우저의 기존 로그인 세션이 사용됩니다. 게임 프로세스나 PC의 임의 파일을 읽지 않습니다.

2. 저장 위치와 Chrome 동기화

캐릭터·경험치·아이템·사냥·퀘스트·메모 등의 기록은 현재 브라우저 프로필의 IndexedDB, localStorage 및 확장프로그램 저장소에 저장됩니다. 마이린 운영자 서버로 이러한 기록을 자동 업로드하지 않습니다.

글씨 크기·굵기, 테마, 메뉴·표시 옵션, 비주류 장비 숨김, 퀘스트 진행도 표시 및 캐릭터별 목표 레벨 등 일부 설정은 Chrome의 동기화 저장소를 사용합니다. 목표 레벨 설정 키에는 캐릭터 식별값이 포함될 수 있습니다. 브라우저 동기화 상태에 따라 Google을 통해 다른 기기로 동기화될 수 있으므로 모든 정보가 PC에만 남는 것은 아닙니다. 경험치·아이템·사냥·메모 등의 전체 기록은 이 설정 동기화에 포함하지 않습니다.

백업을 실행하면 기록과 설정을 사용자가 지정한 파일에 내보냅니다. 복구는 사용자가 선택한 파일을 읽습니다. 백업 파일을 다른 사람에게 전달하면 그 안의 정보도 전달되므로 보관·공유에 유의해 주세요.

3. 외부 통신 및 정보가 전달되는 곳

  • 캐릭터·인벤토리·창고 조회를 위해 캐릭터 이름·서버 등 조회 식별값을 공식 홈페이지에 전송합니다. 아이템 상세 조회에는 아이템 식별값·강화값 등을 api-goats.plaync.com에 요청하며, 공식 사이트 및 playnccdn.com 이미지 서버에서 필요한 이미지를 받을 수 있습니다. 인증이 필요한 요청에는 브라우저가 공식 서비스의 로그인 세션을 사용합니다.
  • NAVER: 시간 보정을 위해 www.naver.com에 시간 확인 요청을 보냅니다. 이 요청에 캐릭터 기록·메모를 첨부하지 않으며 로그인 쿠키를 보내지 않습니다.
  • Google 및 브라우저·운영체제의 음성 서비스: 일부 설정 동기화와 알림 음성 재생에 사용됩니다. 음성 재생 시 알림 이름과 남은 시간 등을 포함한 읽을 문장이 음성 엔진에 전달됩니다. 사용하는 음성이 온라인 음성이면 음성 제공자의 서버에서 처리될 수 있습니다. 마이린이 별도의 음성 녹음 파일을 수집하지는 않습니다.
  • 외부 링크: 추천방송 기능은 비활성화되어 방송 목록을 요청하지 않습니다. 홈페이지·배너 등의 외부 링크를 직접 열면 해당 사이트의 개인정보처리방침이 적용됩니다.
  • 문의 이메일: 사용자가 이메일을 보내면 운영자와 메일 서비스가 발신 주소, 본문 및 첨부파일을 문의 처리 목적으로 취급합니다. 비밀번호·로그인 쿠키 등 인증정보는 보내지 마세요.

외부 서비스는 통신 과정에서 IP 주소·요청 시각 등 일반적인 접속 정보를 처리할 수 있습니다. 이는 각 서비스의 정책에 따릅니다. 마이린은 사용자 기록을 판매하거나 맞춤형 광고·광고 타기팅에 사용하지 않습니다.

4. 요청 권한과 사용 이유

  • scripting: 허용된 공식 홈페이지에서 로그인·캐릭터 정보 확인 및 필요한 페이지 동작을 수행합니다.
  • storage: 기록·설정의 저장과 일부 설정의 동기화에 사용합니다.
  • alarms: 주기적 수집과 예약 알림을 실행합니다.
  • notifications: 브라우저 알림을 표시합니다.
  • tts: 알림 문장을 음성으로 읽습니다.
  • offscreen: 화면에 별도 탭을 표시하지 않고 음성 재생 등의 작업을 처리합니다.
  • 사이트 접근 권한: lineageclassic.plaync.com, *.playnccdn.com, api-goats.plaync.com, www.naver.com에 위 기능 수행을 위해 접근합니다. 모든 웹사이트의 방문 기록을 수집하는 용도로 사용하지 않습니다.

5. 보관 기간과 삭제 방법

사용자 기록은 기능별 삭제, 초기화 또는 브라우저 데이터 삭제 전까지 보관됩니다. 이미지·진단 등 일부 캐시는 프로그램의 관리 기준에 따라 교체·정리될 수 있습니다. 연결 해제나 로그아웃만으로 기존 기록이 삭제되지는 않습니다.

환경설정 → 데이터 → 초기화는 경험치·레벨업·아이템 변동·사냥 기록, 메모·가계부, 가격·기간, 즐겨찾기 및 개인 설정 등을 삭제합니다. 다만 등록된 알림, 직접 만든 버프, 활성 퀘스트 항목은 남깁니다. 퀘스트의 완료·달력 기록은 지우며 알림은 ON 상태로 다시 설정합니다. 게임 도감·제작 같은 프로그램 기본 자료도 유지합니다.

남겨진 항목은 각 기능에서 직접 삭제할 수 있습니다. 확장프로그램 제거 또는 브라우저의 확장프로그램 데이터 삭제로 로컬 데이터를 정리할 수 있습니다. 별도로 저장한 백업 파일, 다른 브라우저 프로필·기기의 데이터 및 Chrome 동기화 정보는 별도로 관리·삭제해야 합니다. 공식 홈페이지의 계정·캐릭터 데이터는 마이린에서 삭제하지 않습니다.

문의 메일은 문의 처리에 필요한 기간 동안 보관하며, 삭제 요청은 아래 주소로 접수할 수 있습니다. 법령상 보관이 필요한 경우 해당 의무가 우선합니다. 운영자는 사용자 PC의 기록을 원격으로 열람하거나 대신 삭제할 수 없습니다.

6. 사용자 선택과 안전한 처리

사용자는 연결·알림 설정을 변경하거나 확장프로그램을 사용 중지·제거할 수 있습니다. 공식 API 및 시간 확인 통신은 HTTPS를 사용합니다. 로컬 기록과 백업 파일을 마이린이 별도의 비밀번호로 암호화하는 것은 아니므로 PC와 브라우저 프로필을 안전하게 관리해 주세요.

마이린의 사용자 데이터 이용은 Chrome 웹스토어 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다. 사용자에게 설명한 기능 제공·개선에 필요한 범위로 사용을 제한하며, 광고 타기팅이나 데이터 판매 목적으로 제공하지 않습니다.
